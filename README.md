# Egypt Income Tax Study Guide (Law 91 of 2005)

An interactive Arabic study guide for tax accounting: the Egyptian Income Tax Law No. 91 of 2005, organised by chapter, with a quick index, one-page review posters, condensed "summary of the summary" lists and worked examples.

**Live site:** https://files.instinct.com/faa4fihem938

## What is in it

- Chapter-by-chapter summaries, from the introduction to Egypt's tax system through the eight chapters of the course
- 34 visual review posters, one or more per chapter
- A fast navigation index across chapters and sections
- Right-to-left Arabic layout that works on phone and desktop

## How it was built

Built with AI-assisted development (Claude Code): agentic coding workflows, prompt engineering and iterative prototyping, by Mohamed Ayman Harash.

## Run it

This repository holds the built static site. There is no build step.

1. Download or clone the repository.
2. Serve the folder with any static server, for example `python3 -m http.server`, and open `http://localhost:8000`.

Opening `index.html` directly from disk may not work in every browser, so use a local server.

## Note

This is a student study aid. It is not legal or tax advice. Check the law and your textbook for anything that matters.
